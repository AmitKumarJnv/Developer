"# Python Refresher

This folder contains a beginner-friendly Python refresher covering the core programming concepts used throughout the FastAPI course.

## What this section includes

- Variables, comments, and user input
- Strings, lists, dictionaries, sets, and tuples
- Conditional statements and loops
- Functions and imports
- Object-oriented programming and inheritance
- Practice assignments to reinforce each topic

## Suggested learning order

1. Start with the basics in the Variables, Comments, and User Input folders.
2. Move on to data structures such as Lists, Dictionaries, and Sets and Tuples.
3. Practice logic with If Else, Loops, and Boolean and Operators.
4. Learn reusable code with Functions and Imports.
5. Finish with OOP and Inheritance for object-oriented programming concepts.

## How to use these files

- Open each folder and read the examples first.
- Try the practice files by running them with Python.
- Revisit topics whenever you need a quick refresher while building FastAPI projects.

Example:

```bash
python3 filename.py
```

This refresher is meant to build a strong foundation before moving into FastAPI application development."
